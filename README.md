# 极速热场 · 校园漂移赛

60 秒手机竖屏体感赛车，配套主持台和横屏实时排名。车辆、道路、障碍和粒子采用 Kenney 原版 CC0 素材；界面使用 Ville Seppänen 的 Racing UI Kit，氮气瓶使用 Vector Squad 的公开图标。

## 使用入口

- 首页：`/`
- 单人试驾：`/?practice=1`
- 创建比赛：`/?mode=host`
- 主持台：`/?host=六位房间号`，主持凭证只保存在创建房间的浏览器本地，不放入 URL。
- 玩家入口：`/?room=六位房间号`
- 纯大屏：`/?screen=六位房间号`

主持台创建房间后显示参赛二维码。玩家加入、选择赛车，先选择“体感驾驶”或“按键驾驶”。体感需要授权并收到有效方向数据完成校准，按键使用下方 ← → 转向；驾驶方式就绪后才可点击“我已准备”。准备状态在手机刷新后保留，可点击取消。刷新已准备的页面时明确切到按键驾驶；体感需取消准备后重新开启、校准，避免沿用失效的体感状态。弱网下延迟到达的旧准备响应不会覆盖较新的准备／取消状态。至少一位在线车手且所有在线车手都准备后，主持人才可以统一发车；倒计时 5 秒，正式比赛 60 秒，随后有 5 秒网络成绩同步时间。结算后可导出全部成绩、保留参赛者再来一局。手机可在原页面内查看全场成绩，仍持续在线；主持人重开后会自动回到准备页。主持台可选择历局成绩并导出，重开不再清除已完成比赛的记录。

房间人数显示当前在线人数，并分别显示已加入、已准备和离线人数。15 秒未收到车手请求视为离线；等待阶段重连后需重新准备。主持人可在准备阶段移除任意入场车手；车手可主动退出。发车时锁定在线且已准备的参赛名单，未入选者等待下一局。比赛中断线或主动退出不会改变本局总参赛人数和最终成绩记录。重开会清空准备状态，已退出或移除的车手不会自动回来。

手机左右倾斜转向，左下按住漂移，右下按住加速；两个键可同时按住。体感不可用时支持触控方向键。电脑支持左右方向键、向上键/空格加速、Shift 漂移。比赛中刷新页面会释放原先按住的油门、漂移和转向，避免无人按键仍继续加速。

## 已实现规则

- 不按加速时，正常车速逐渐趋近 30 码：低于 30 自动提高，高于 30 逐渐回落。
- 按住加速，正常车速逐渐增加至 120；从静止到 120 约 8 秒。
- 氮气对持续变化的正常车速乘 1.3，保持 3 秒，再用 2 秒消退；普通最高速度 120，氮气最高 156。
- 再次吃到氮气刷新满额 3 秒，不继续叠加倍率。
- 氮气使用蓝色 N₂O 瓶、障碍使用橙色长条路障，并配有文字标签。氮气生效时车尾显示蓝色双喷焰，在消退阶段随加成缩短。
- 障碍减速 50%，持续 3 秒；与氮气同时生效，同类障碍刷新时间。
- 30 是正常巡航目标，不是道具作用后的最低实际车速。
- 漂移提高转向灵敏度并减速 8%，同时保留横向惯性：按住漂移并转向会产生侧滑，松开后逐渐回正。连续弯道需修正方向；路沿限制整个车身，不能驶入草地。
- 所有人使用相同的赛道对象序列。赛车之间不碰撞，按沿赛道累计前进距离排名。
- 排名、手机结算、大屏领奖台及 CSV 统一按 0.1 米精度；同距离并列，名次如 1、1、3。并列车手共享相应冠军／亚军／季军位置，不按内部 ID 分胜负。
- 服务端重放玩家的操作输入，统一计算道具碰撞和距离，不接受客户端上报的距离分数。
- 断线后自动重连、补交已记录的操作；最终同步窗口结束后，未收到的操作按最后输入最多保持 1 秒，再转为正常巡航结算。

## 本地运行

需要 Node.js 22.13 或以上版本。依赖版本锁定在 package-lock.json。

```bash
npm run install:ci
npm run build
node --import ./scripts/sites-env.mjs ./node_modules/wrangler/bin/wrangler.js d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/0000_youthful_iron_monger.sql
node --import ./scripts/sites-env.mjs ./node_modules/wrangler/bin/wrangler.js d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/0001_easy_union_jack.sql
node --import ./scripts/sites-env.mjs ./node_modules/wrangler/bin/wrangler.js d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/0002_real_gunslinger.sql
npm start -- --port 5173
```

迁移按编号各执行一次，后续启动不用重放。已有数据库只补执行尚未应用的迁移：`0001_easy_union_jack.sql` 保留已有车手及已开局成绩；`0002_real_gunslinger.sql` 新增准备状态版本和历局成绩表。若已经执行 0001，只需补 0002。历史成绩从本次更新开始保存；更新前已经重开而丢失的成绩无法恢复。需要热更新时可改用 `npm run dev -- --port 5173`。

手机体感正式使用需要 HTTPS。localhost 二维码仅供本机测试，不能用于现场其他手机；现场应使用发布后的公网 HTTPS 地址。
